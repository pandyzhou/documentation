Meilisearch **能够为你的内容建立高效索引，并使其轻松服务于人类与 AI**。它支持存储你的文档与向量嵌入（Embeddings），并通过统一的 API 提供极速全文检索、语义搜索以及对话式交互能力。

## 工作原理

**一次建索，处处可用。** 你只需将内容推送到 Meilisearch 中，它会自动存储文档、构建搜索索引；当配置了向量嵌入器（Embedder）时，它还会全自动生成向量。你的数据将瞬间具备服务最终用户与 AI 系统的能力。

## 你可以用它构建什么？

- **即时搜索界面**：为网站、移动端应用或知识库文档打造毫秒级响应、自带错别字容错的搜索框。
- **AI 智能助手**：通过内置的 RAG 能力将大模型与你的私有内容连接。用户可以用自然语言提问，并获得基于真实数据的可靠回答。
- **智能推荐系统**：自动发现相似内容，并结合用户偏好提供个性化推荐。
- **企业内部工具**：打通散落在各类文档、业务数据库和 API 中的企业知识，实现跨系统秒级统一检索。

## 为什么选择 Meilisearch？

Meilisearch 的设计基于三大核心支柱：

### 极致性能 (Performance)

Meilisearch 为大规模高并发场景下的极速响应而生。无论你的索引里只有几千篇文档还是数千万行数据，绝大多数查询都能在 **50 毫秒**以内返回。底层引擎采用内存映射存储（LMDB）、多线程并行索引流水线以及基于 DiskANN 的向量搜索，随着数据规模增长依然能保持高度稳定的检索延迟。同时支持分片（Sharding）与主从复制，帮助你在不牺牲低延迟的前提下实现水平弹性扩容。

### 精准相关度 (Relevancy)

呈现精准的检索结果依赖多种信号的综合权衡。Meilisearch 默认串联了 7 项排序规则（词频匹配 words、拼写容错 typo、词距 proximity、属性权重 attributeRank、自定义排序 sort、命中词位置 wordPosition 以及精确度 exactness），并且完全支持根据你的业务场景定制规则。其混合搜索（Hybrid Search）融合了关键词与向量语义，即使用户没有用对准确关键词，也能精准召回想要的结果。对话式搜索更进一步：基于 RAG 的回答全部严格锚定在你的已索引数据中，确保 AI 回复有据可查、杜绝幻觉。

### 优秀的开发者体验 (Developer Experience)

Meilisearch 是一个带有 REST API 的单一独立二进制文件。你不需要像 Elasticsearch 那样搭建维护复杂的分布式集群，不需要提前定义死板的表结构 Schema，更不需要额外维护独立的向量数据库。只要把 JSON 文档发给它，Meilisearch 会自动处理分词、倒排索引以及向量生成。加之覆盖 10+ 种主流编程语言的 SDK、Meilisearch Cloud 的一键部署以及极其合理的默认配置，让你在数分钟而不是数周内，就能把生产级搜索系统上线运行。
