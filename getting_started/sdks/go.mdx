本指南引导你使用 Go 语言与 Meilisearch 快速建立连接、写入数据并实现检索。

## 环境准备

- Go 1.16 或更高版本
- 一个运行中的 Meilisearch 实例（[Meilisearch Cloud](https://cloud.meilisearch.com) 或 [自托管部署](/resources/self_hosting/getting_started/quick_start)）

## 1. 安装 Go SDK

```bash
go get github.com/meilisearch/meilisearch-go
```

## 2. 建立客户端连接

```go
package main

import (
    "os"
    "github.com/meilisearch/meilisearch-go"
)

func main() {
    client := meilisearch.New(
        os.Getenv("MEILISEARCH_URL"),
        meilisearch.WithAPIKey(os.Getenv("MEILISEARCH_KEY")),
    )
}
```

<Note>
**配置你的环境变量：**
```bash
export MEILISEARCH_URL="https://your-instance.meilisearch.io"  # 本地开发可设为 http://localhost:7700
export MEILISEARCH_KEY="your_api_key"
```
[免费获取 Cloud 云端实例 →](https://cloud.meilisearch.com)
</Note>

## 3. 批量添加文档

```go
type Movie struct {
    ID     int      `json:"id"`
    Title  string   `json:"title"`
    Genres []string `json:"genres"`
    Year   int      `json:"year"`
}

movies := []Movie{
    {ID: 1, Title: "黑客帝国 (The Matrix)", Genres: []string{"动作", "科幻"}, Year: 1999},
    {ID: 2, Title: "盗梦空间 (Inception)", Genres: []string{"动作", "悬疑"}, Year: 2010},
    {ID: 3, Title: "星际穿越 (Interstellar)", Genres: []string{"剧情", "科幻"}, Year: 2014},
}

// 向 'movies' 索引添加文档
task, _ := client.Index("movies").AddDocuments(movies)

// 等待异步建索任务执行完毕
client.WaitForTask(task.TaskUID)
```

## 4. 执行搜索

```go
results, _ := client.Index("movies").Search("matrix", nil)

fmt.Println(results.Hits)
```

## 5. 结合布尔过滤器检索

首先配置可过滤字段：

```go
client.Index("movies").UpdateFilterableAttributes(&[]string{"genres", "year"})
```

然后执行带过滤条件的搜索：

```go
results, _ := client.Index("movies").Search("", &meilisearch.SearchRequest{
    Filter: "genres = '科幻' AND year > 2000",
})
```

## 完整可运行代码示例

```go
package main

import (
    "fmt"
    "os"
    "github.com/meilisearch/meilisearch-go"
)

type Movie struct {
    ID     int      `json:"id"`
    Title  string   `json:"title"`
    Genres []string `json:"genres"`
    Year   int      `json:"year"`
}

func main() {
    client := meilisearch.New(
        os.Getenv("MEILISEARCH_URL"),
        meilisearch.WithAPIKey(os.Getenv("MEILISEARCH_KEY")),
    )

    // 添加测试文档
    movies := []Movie{
        {ID: 1, Title: "黑客帝国 (The Matrix)", Genres: []string{"动作", "科幻"}, Year: 1999},
        {ID: 2, Title: "盗梦空间 (Inception)", Genres: []string{"动作", "悬疑"}, Year: 2010},
        {ID: 3, Title: "星际穿越 (Interstellar)", Genres: []string{"剧情", "科幻"}, Year: 2014},
    }

    task, _ := client.Index("movies").AddDocuments(movies)
    client.WaitForTask(task.TaskUID)

    // 执行关键词检索
    results, _ := client.Index("movies").Search("inter", nil)
    fmt.Println(results.Hits)
}
```
