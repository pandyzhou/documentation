本指南带你使用 Python 与 Meilisearch 快速建立连接、写入数据并实现检索。

## 环境要求

- Python 3.8 或更高版本
- 一个运行中的 Meilisearch 实例（[Meilisearch Cloud](https://cloud.meilisearch.com) 或 [自托管部署](/resources/self_hosting/getting_started/quick_start)）

## 1. 安装 Python SDK

```bash
pip install meilisearch
```

## 2. 建立客户端连接

```python
import meilisearch
import os

client = meilisearch.Client(
    os.environ.get('MEILISEARCH_URL'),
    os.environ.get('MEILISEARCH_KEY')
)
```

<Note>
**配置环境变量：**
```bash
export MEILISEARCH_URL="https://your-instance.meilisearch.io"  # 本地开发可设为 http://localhost:7700
export MEILISEARCH_KEY="your_api_key"
```
[免费获取 Cloud 云端实例 →](https://cloud.meilisearch.com)
</Note>

## 3. 批量添加文档

```python
movies = [
    {'id': 1, 'title': '黑客帝国 (The Matrix)', 'genres': ['动作', '科幻'], 'year': 1999},
    {'id': 2, 'title': '盗梦空间 (Inception)', 'genres': ['动作', '悬疑'], 'year': 2010},
    {'id': 3, 'title': '星际穿越 (Interstellar)', 'genres': ['剧情', '科幻'], 'year': 2014}
]

# 向 'movies' 索引添加文档
task = client.index('movies').add_documents(movies)

# 等待异步建索任务完成
client.wait_for_task(task.task_uid)
```

## 4. 执行搜索

```python
results = client.index('movies').search('matrix')

print(results['hits'])
```

## 5. 结合过滤器检索

首先配置可过滤属性：

```python
client.index('movies').update_filterable_attributes(['genres', 'year'])
```

然后执行带过滤条件的搜索：

```python
results = client.index('movies').search('', {
    'filter': 'genres = "科幻" AND year > 2000'
})
```

## 完整代码示例

```python
import meilisearch
import os

client = meilisearch.Client(
    os.environ.get('MEILISEARCH_URL'),
    os.environ.get('MEILISEARCH_KEY')
)

# 添加数据
movies = [
    {'id': 1, 'title': '黑客帝国 (The Matrix)', 'genres': ['动作', '科幻'], 'year': 1999},
    {'id': 2, 'title': '盗梦空间 (Inception)', 'genres': ['动作', '悬疑'], 'year': 2010},
    {'id': 3, 'title': '星际穿越 (Interstellar)', 'genres': ['剧情', '科幻'], 'year': 2014}
]

task = client.index('movies').add_documents(movies)
client.wait_for_task(task.task_uid)

# 执行搜索
results = client.index('movies').search('inter')
print(results['hits'])
```
