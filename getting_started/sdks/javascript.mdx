本指南带你使用 JavaScript / Node.js 与 Meilisearch 快速建立连接、写入数据并实现检索。

## 环境要求

- Node.js 14 或更高版本
- 一个运行中的 Meilisearch 实例（[Meilisearch Cloud](https://cloud.meilisearch.com) 或 [自托管部署](/resources/self_hosting/getting_started/quick_start)）

## 1. 安装 JavaScript SDK

```bash
npm install meilisearch
# 或使用 yarn
yarn add meilisearch
# 或使用 pnpm
pnpm add meilisearch
```

## 2. 建立客户端连接

```javascript
import { Meilisearch } from 'meilisearch'

const client = new Meilisearch({
  host: process.env.MEILISEARCH_URL,
  apiKey: process.env.MEILISEARCH_KEY
})
```

<Note>
**配置环境变量：**
```bash
export MEILISEARCH_URL="https://your-instance.meilisearch.io"  # 本地开发可设为 http://localhost:7700
export MEILISEARCH_KEY="your_api_key"
```
[免费获取 Cloud 云端实例 →](https://cloud.meilisearch.com)
</Note>

## 3. 批量添加文档

```javascript
const movies = [
  { id: 1, title: '黑客帝国 (The Matrix)', genres: ['动作', '科幻'], year: 1999 },
  { id: 2, title: '盗梦空间 (Inception)', genres: ['动作', '悬疑'], year: 2010 },
  { id: 3, title: '星际穿越 (Interstellar)', genres: ['剧情', '科幻'], year: 2014 }
]

// 向 'movies' 索引添加文档
const task = await client.index('movies').addDocuments(movies)

// 等待异步建索任务完成
await client.waitForTask(task.taskUid)
```

## 4. 执行搜索

```javascript
const results = await client.index('movies').search('matrix')

console.log(results.hits)
```

## 5. 结合过滤器检索

首先配置可过滤属性：

```javascript
await client.index('movies').updateFilterableAttributes(['genres', 'year'])
```

然后执行带过滤条件的搜索：

```javascript
const results = await client.index('movies').search('', {
  filter: 'genres = "科幻" AND year > 2000'
})
```

## 完整代码示例

```javascript
import { Meilisearch } from 'meilisearch'

const client = new Meilisearch({
  host: process.env.MEILISEARCH_URL,
  apiKey: process.env.MEILISEARCH_KEY
})

async function main() {
  // 添加数据
  const movies = [
    { id: 1, title: '黑客帝国 (The Matrix)', genres: ['动作', '科幻'], year: 1999 },
    { id: 2, title: '盗梦空间 (Inception)', genres: ['动作', '悬疑'], year: 2010 },
    { id: 3, title: '星际穿越 (Interstellar)', genres: ['剧情', '科幻'], year: 2014 }
  ]

  const task = await client.index('movies').addDocuments(movies)
  await client.waitForTask(task.taskUid)

  // 执行搜索
  const results = await client.index('movies').search('inter')
  console.log(results.hits)
}

main()
```
