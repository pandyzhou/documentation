Meilisearch 为你的内容建立索引，并使其轻松服务于人类与 AI。以下是其全部核心功能特性概览。

## 搜索能力

### 全文检索 (Full-text search)

自带拼写容错、响应极快且支持高度定制排序规则的关键词搜索。

| 功能特性 | 功能描述 |
| :--- | :--- |
| **50ms 内极速响应** | 无论数据集规模大小，始终保持亚 50 毫秒级的极速检索 |
| **[错别字容错](/capabilities/full_text_search/relevancy/typo_tolerance_settings)** | 即使用户输入拼写错误，依然能准确召回相关结果 |
| **[排序规则](/capabilities/full_text_search/relevancy/ranking_rules)** | 内置 6 大基础规则，并支持针对特定业务的自定义排序规则 |
| **[相关度打分](/capabilities/full_text_search/relevancy/ranking_score)** | 返回综合相关度得分，并可选返回详细的打分拆解明细 |
| **[同义词支持](/capabilities/full_text_search/relevancy/synonyms)** | 定义等价词组映射，显著提升搜索召回率 |
| **[停用词过滤](/reference/api/settings/get-stopwords)** | 自动忽略如 "the"、"and" 或虚词等无实际搜索价值的高频词 |
| **[结果去重字段](/capabilities/full_text_search/how_to/configure_distinct_attribute)** | 针对指定字段（Distinct Attribute）对搜索结果进行自动去重 |
| **[前缀即搜](/resources/internals/prefix)** | 支持前缀匹配，随着用户键盘敲击实时更新搜索结果 |
| **[匹配策略](/reference/api/search/search-with-post#body-matching-strategy)** | 灵活控制多词匹配方式：`last`（按顺序回退）、`all`（全包含）或 `frequency`（词频优先） |
| **[精准短语搜索](/reference/api/search/search-with-post)** | 使用双引号精确检索包含连续完整短语的文档 |
| **[负向词排除](/reference/api/search/search-with-post)** | 使用减号运算符（如 `-手机`）从结果中排除包含特定词的内容 |
| **[占位符检索](/reference/api/search/search-with-post)** | 当搜索词为空时，返回排序后的全部文档（空搜索/默认推荐） |

### 查询与结果格式化

| 功能特性 | 功能描述 |
| :--- | :--- |
| **[关键词高亮](/reference/api/search/search-with-post#highlight-tags)** | 自动在结果中高亮命中的关键词，支持自定义 HTML 标签 |
| **[文本智能裁剪](/reference/api/search/search-with-post#body-attributes-to-crop)** | 对超长文本字段自动提取包含命中词的前后相关上下文摘要 |
| **[命中位置标记](/reference/api/search/search-with-post#body-show-matches-position)** | 返回命中词在原文中的字节偏移量（Byte Position）与长度 |
| **[搜索熔断保护](/reference/api/settings/get-searchcutoffms)** | 设置单次搜索的最长超时软阈值，超时则返回已计算的最佳结果，防爆内存 |
| **[深度分词定制](/capabilities/indexing/advanced/tokenization)** | 定制词条切分规则，支持自定义分隔符与用户词典 |

### AI 智能搜索 (AI-powered search)

基于向量嵌入（Vector Embeddings）的语义搜索与混合搜索，实现基于语境含义的智能理解。

| 功能特性 | 功能描述 |
| :--- | :--- |
| **[混合搜索 (Hybrid Search)](/capabilities/hybrid_search/getting_started)** | 融合传统关键词搜索（BM25）与向量语义搜索的优势 |
| **[主流向量嵌入器支持](/capabilities/hybrid_search/how_to/choose_an_embedder)** | 原生支持 OpenAI、Hugging Face、Cohere、Mistral、Voyage、Gemini、Cloudflare、Ollama 及自定义 REST API |
| **[相似内容推荐](/capabilities/personalization/getting_started/recommendations)** | 传入文档 ID 自动查找语义最相似的其他内容 |
| **[以图搜图/多模态](/capabilities/hybrid_search/how_to/image_search_with_multimodal)** | 基于多模态嵌入模型实现图像与文字之间的跨模态检索 |
| **[多嵌入器共存](/reference/api/settings/get-embedders)** | 同一文档可绑定多个不同维度的向量嵌入模型 |
| **[自带向量导入](/capabilities/hybrid_search/how_to/search_with_user_provided_embeddings)** | 支持直接写入用户在外部预先计算好的向量数据 |

### 智能体与对话搜索 (Agentic search)

通过与大语言模型（LLM）深度集成，让 AI 智能体与聊天交互直接连接你的结构化数据。

| 功能特性 | 功能描述 |
| :--- | :--- |
| **[AI SDK 集成](/getting_started/integrations/ai_sdk)** | 结合 Vercel AI SDK，将 Meilisearch 作为标准 Tool 工具赋能智能体 |
| **[原生 Chats API](/capabilities/agentic_search/advanced/chats_api)** | 引擎内置托管的对话搜索方案，直接调用 `/chats` 端点对话 |
| **[大模型提供商](/capabilities/agentic_search/advanced/chats_api#workspace-settings)** | 支持接入 OpenAI、Azure OpenAI、Mistral 及自建 vLLM 服务 |
| **[流式响应 (Streaming)](/reference/api/chats/request-a-chat-completion)** | 支持以 SSE 流式打字机效果实时输出对话回复 |
| **[对话工作空间](/reference/api/chats/get-settings-of-a-chat-workspace)** | 按索引维度单独配置对话系统提示词、温度与检索策略 |

### 个性化 (Personalization)

| 功能特性 | 功能描述 |
| :--- | :--- |
| **[用户偏好重排](/reference/api/search/search-with-post#body-personalize-one-of-1)** | 借助 AI 向量，根据个体用户的历史行为和偏好对搜索结果重新加权打分 |
| **实时自适应** | 随着用户互动偏好的变化，动态微调搜索排序结果 |

### 过滤与多维分面 (Filtering and faceting)

使用强大的过滤表达式细化结果，并搭建专业电商级的分面筛选导航。

| 功能特性 | 功能描述 |
| :--- | :--- |
| **[灵活过滤器](/capabilities/filtering_sorting_faceting/getting_started)** | 支持通过复杂的布尔表达式（AND/OR/NOT/IN/比较符）对任意字段筛选 |
| **[分面导航](/capabilities/filtering_sorting_faceting/how_to/filter_with_facets)** | 毫秒级返回各大分类维度的数值分布统计，轻松搭建侧边筛选器 |
| **[丰富分面类型](/capabilities/filtering_sorting_faceting/overview)** | 支持数值区间、布尔开关、标签集合与日期范围分面 |
| **[多字段排序](/capabilities/filtering_sorting_faceting/how_to/sort_results)** | 任意指定升序或降序字段（如价格由低到高、时间由新到旧） |
| **[地理位置搜索](/capabilities/geo_search/getting_started)** | 支持半径圆形范围（Radius）、矩形边界框（Bounding Box）、多边形过滤及距离排序 |

### 多索引搜索与联合搜索 (Multi-search and federation)

在单次 HTTP 请求中并发检索多个不同索引，应对复杂业务聚合场景。

| 功能特性 | 功能描述 |
| :--- | :--- |
| **[多索引并发搜索](/capabilities/multi_search/overview)** | 单次请求并发查询多个独立索引（如同时查商品和用户） |
| **[联合搜索 (Federation)](/capabilities/multi_search/getting_started/federated_search)** | 跨多个数据源归并结果，并支持按权重统一混排为一个总列表 |

| **[函数式原子编辑](/reference/api/documents/edit-documents-by-function)** | 通过简单函数逻辑对一批文档的部分属性进行原子增减计算 |
| **[可搜索属性设置](/capabilities/full_text_search/how_to/configure_displayed_attributes)** | 精细化指定哪些字段参与全文搜索，以及各字段的优先级权重 |

| 功能特性 | 功能描述 |
| :--- | :--- |

## 语言与本地化支持

Meilisearch 对全球多种语言文字体系提供了深度专项分词与规范化优化：

- **拉丁语系**：英语、法语、西班牙语、德语、意大利语、葡萄牙语等。
- **中日韩 (CJK)**：针对**中文**、日文、韩文进行了专门的切词与无空格断词优化。
- **从右向左阅读语言 (RTL)**：希伯来语、阿拉伯语。
- **其他语种**：泰语、希腊语等。

[查看全部受支持语言与分词详情 →](/resources/help/language)
