AI 驱动的搜索使用**向量嵌入模型（Embedding models）**，根据查询词背后的深层含义与语境召回结果，而不再局限于死板的关键词字面匹配。与消耗惊人的大语言模型（LLMs）不同，嵌入模型极为轻量、计算快速且成本极低。

本教程以最易上手配置的 OpenAI 作为向量提供商为例。Meilisearch 还支持[众多其他服务商](/capabilities/hybrid_search/overview#supported-embedder-providers)，包括本地部署的 Ollama、Cohere、Mistral、Gemini、Cloudflare、Voyage 等。

<Note>
跟随本教程需要准备一个 [OpenAI API Key](https://platform.openai.com/api-keys)（若使用国内模型或本地 Ollama，配置方式完全相同）。
</Note>

## 准备工作：创建索引并导入数据

创建名为 `kitchenware`（厨具）的索引，并导入[这份示例厨具数据集](/assets/datasets/kitchenware.json)。

## 配置向量嵌入器 (Embedder)

Meilisearch 使用**嵌入器（Embedder）**将文档与用户的查询词转换为高维向量（Embeddings）。一旦配置完成，后续全量文档的向量计算与增量缓存全部由引擎自动托管。

### 1. 命名嵌入器
在配置对象中为你的嵌入器起一个简洁易记的名字，例如 `products-openai`：

<CodeGroup>

```json
{
  "products-openai": {}
}
```

</CodeGroup>

### 2. 指定驱动源 (Source)
添加 `source` 属性指定提供商：

<CodeGroup>

```json
{
  "products-openai": {
    "source": "openAi"
  }
}
```

</CodeGroup>

### 3. 选择具体的向量模型 (Model)
指定 `model` 字段。例如选择高性价比的 `text-embedding-3-small`：

<CodeGroup>

```json
{
  "products-openai": {
    "source": "openAi",
    "model": "text-embedding-3-small"
  }
}
```

</CodeGroup>

### 4. 填入 API 密钥与凭据
填入你的 `apiKey`：

<CodeGroup>

```json
{
  "products-openai": {
    "source": "openAi",
    "model": "text-embedding-3-small",
    "apiKey": "YOUR_OPEN_AI_API_KEY"
  }
}
```

</CodeGroup>

### 5. 设计文档模版 (Document Template)
真实文档通常包含多个复杂字段。**文档模版**利用 [Liquid 模版语法](https://shopify.github.io/liquid/basics/introduction/) 指导 Meilisearch 应该把哪些核心文字提取出来送给模型去“理解”：

<CodeGroup>

```json
{
  "products-openai": {
    "source": "openAi",
    "model": "text-embedding-3-small",
    "apiKey": "YOUR_OPEN_AI_API_KEY",
    "documentTemplate": "厨房用品，名称为'{{doc.name}}'"
  }
}
```

</CodeGroup>

模版提供了基础语境（厨房用品），并填入了每篇文档特有的名称（如木勺、擀面杖）。

### 6. 提交配置给 Meilisearch
调用索引设置更新接口提交上述配置：

<CodeSamplesAiSearchGettingStartedEmbedders1 />

Meilisearch 会在后台全自动将文档切片批处理，并异步向模型提供商请求生成向量。向量一旦生成就会自动持久化缓存。

## 执行混合搜索 (Hybrid Search)

混合搜索的调用方式与普通搜索几乎完全一样，只需在 `/search` 请求体中额外携带 `hybrid` 参数：

<CodeSamplesAiSearchGettingStartedSearch1 />

Meilisearch 会在底层同时并发执行关键词与向量搜索，并通过内置的[智能打分排序算法](/capabilities/hybrid_search/overview#smart-result-ranking)自动将最契合的结果排在最前列。

<Tip>
当某个查询词在你的索引中完全没有匹配时，纯语义搜索有时可能召回相关度偏弱的边缘结果。使用 `rankingScoreThreshold` 参数可以过滤掉得分低于设定阈值的弱相关结果：

```json
{
  "q": "适合热菜的盘子",
  "hybrid": { "semanticRatio": 0.9, "embedder": "products-openai" },
  "rankingScoreThreshold": 0.5
}
```

取值范围为 `0.0` 到 `1.0`，通常设置在 `0.5` 左右即可有效过滤噪音。
</Tip>
