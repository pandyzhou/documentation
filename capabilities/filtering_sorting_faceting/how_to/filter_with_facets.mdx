在 Meilisearch 中，分面（Facets）是一种能够同时返回分类聚合统计数据的专业过滤器。本指南通过模拟图书数据集，手把手教你如何配置分面、获取分类项的命中分布统计，以及直接对分面值本身进行搜索。

## 配置分面索引设置

假设你有一批图书数据集：

<CodeGroup>

```json
{
  "id": 5,
  "title": "Hard Times",
  "genres": ["Classics","Fiction", "Victorian", "Literature"],
  "publisher": "Penguin Classics",
  "language": "English",
  "author": "Charles Dickens",
  "description": "Hard Times is a novel of social […] ",
  "format": "Hardcover",
  "rating": 3
}
```

</CodeGroup>

将 `genres`（题材）、`language`（语言）和 `rating`（评分）添加到 `filterableAttributes` 列表中：

<CodeSamplesFacetedSearchUpdateSettings1 />

至此，你的索引已经准备就绪，可以随时利用这些字段执行分面筛选与统计。

## 在搜索请求中使用分面

在普通的搜索请求中，传入 `facets` 参数指定需要统计的字段列表：

<CodeSamplesFacetedSearch1 />

响应不仅会返回匹配的书籍列表，还会额外返回专用于搭建电商侧边栏的两个核心字段：`facetDistribution`（分布统计）与 `facetStats`（数值极值）：

<CodeGroup>

```json
{
  "hits": [
    …
  ],
  …
  "facetDistribution": {
    "genres": {
      "Classics": 6,
      …
    },
    "language": {
      "English": 6,
      "French": 1,
      "Spanish": 1
    },
    "rating": {
      "2.5": 1,
      …
    }
  },
  "facetStats": {
    "rating": {
      "min": 2.5,
      "max": 4.7
    }
  }
}
```

</CodeGroup>

- `facetDistribution`：列出当前搜索命中文档所涵盖的所有分面属性值，以及**每个分类值分别拥有多少条结果**。
- `facetStats`：针对所有数值型字段，返回当前搜索结果中的**最小值 (min) 与最大值 (max)**（非常适合直接渲染价格滑块或评分区间组件）。

### 分面值的展示排序规则

默认情况下，所有的分面值按照字母数字升序排列。你可以通过修改 [`faceting` 索引设置](/reference/api/settings/get-faceting) 中的 `sortFacetValuesBy` 属性，将其改为**按结果数量由多到少排序（Count 降序）**：

<CodeSamplesFacetSearch2 />

使用该设置后，数量最多的分类（如科幻 8 本、文学 7 本、经典 6 本）将自动排在侧边栏最前排：

<CodeGroup>

```json
{
  …
  "facetDistribution": {
    "genres": {
      "Fiction": 8,
      "Literature": 7,
      "Classics": 6,
      "Novel": 2,
      "Horror": 2
    }
  }
}
```

</CodeGroup>

## 检索分面值本身 (Facet Search)

当某个分类下的选项成百上千（例如品牌或分类标签有几千个）时，前端侧边栏需要一个专门的“搜索分类标签”小搜索框。

你可以使用专用的[分面搜索接口](/reference/api/facet-search/search-for-facet-values)：

<CodeSamplesFacetSearch3 />

例如在 `genres` 题材分面中搜索以字母 `c` 开头的分类：

<CodeGroup>

```json
{
  …
  "facetHits": [
    {
      "value": "Children's Literature",
      "count": 1
    },
    {
      "value": "Classics",
      "count": 6
    },
    {
      "value": "Comedy",
      "count": 2
    },
    {
      "value": "Coming-of-Age",
      "count": 1
    }
  ],
  "facetQuery": "c"
}
```

</CodeGroup>

## 获取绝对精准的分面计数

默认情况下，分面搜索返回的各分类命中数量是经过极速算法预估的（在极大规模数据下响应极快）。

如果你在商城前台等场景要求数字必须 100% 精确，在请求中加上 `"exhaustiveFacetCount": true`：

<CodeGroup>

```bash
curl \
  -X POST 'MEILISEARCH_URL/indexes/books/facet-search' \
  -H 'Content-Type: application/json' \
  --data-binary '{
    "facetName": "genres",
    "facetQuery": "c",
    "exhaustiveFacetCount": true
  }'
```

</CodeGroup>
