占位符搜索（Placeholder search）是指在搜索请求中查询字符串 `q` 为空或缺省的检索模式。此时 Meilisearch 不会返回空列表，而是从索引中提取文档返回，同时严格遵守所有其他搜索参数，如[过滤器 (Filters)](/capabilities/filtering_sorting_faceting/getting_started)、[排序 (Sorting)](/capabilities/filtering_sorting_faceting/how_to/sort_results) 以及[分面统计 (Facets)](/capabilities/filtering_sorting_faceting/how_to/filter_with_facets)。

这在以下场景尤其实用：在落地页展示默认内容、展示热门商品，或允许用户在开始打字前直接浏览全部数据。

## 工作原理

当 Meilisearch 收到空查询的搜索请求时，它会彻底跳过文本分词匹配阶段。文档的排列顺序完全由处于生效状态的[排序规则 (Ranking rules)](/capabilities/full_text_search/relevancy/ranking_rules)决定，其中[自定义排序规则](/capabilities/full_text_search/relevancy/custom_ranking_rules)与请求中的 `sort` 参数起主导作用。

由于不涉及任何关键词，基于文本字面的排序规则（如 `words` 词频、`typo` 错字、`proximity` 词距以及 `exactness` 精确度）会自动失效，仅有 `sort` 与自定义规则会影响最终结果的排位。

## 基础示例

发送一个查询词为空字符串的搜索请求：

<CodeGroup>

```bash
curl \
  -X POST 'MEILISEARCH_URL/indexes/movies/search' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer MEILISEARCH_KEY' \
  --data-binary '{
    "q": ""
  }'
```

</CodeGroup>

Meilisearch 会按默认顺序直接返回 `movies` 索引中的前排文档。

## 结合过滤与排序

当占位符搜索与过滤、排序结合时，表现尤为出众。例如直接展示特定分类下评分最高的前排电影：

<CodeGroup>

```bash
curl \
  -X POST 'MEILISEARCH_URL/indexes/movies/search' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer MEILISEARCH_KEY' \
  --data-binary '{
    "q": "",
    "filter": "genres = Action",
    "sort": ["rating:desc"]
  }'
```

</CodeGroup>

无需用户输入任何搜索词，直接返回按评分降序排列的所有动作电影。

## 结合分面统计

你还可以在占位符搜索中同时请求分面分布统计，用于在页面初次加载时渲染分类侧边栏：

<CodeGroup>

```bash
curl \
  -X POST 'MEILISEARCH_URL/indexes/movies/search' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer MEILISEARCH_KEY' \
  --data-binary '{
    "q": "",
    "facets": ["genres", "release_year"]
  }'
```

</CodeGroup>

响应体中将包含 `facetDistribution` 对象，展示各个分类和年份下现存的文档总数。

## 常见业务应用场景

- **首页推荐**：在用户刚进入搜索页面、尚未输入任何内容时，展示热门内容或最新发布
- **分类导航浏览**：将空搜索与分类 Filter 结合，把搜索界面当作常规分类列表页使用
- **默认趋势推荐**：按自定义排序字段（如 `popularity` 热度）降序，自动呈现热搜榜单
- **分面聚合导航**：展示各个类别的文档数量徽标，引导用户点击筛选

## 分页控制

占位符搜索与普通搜索支持完全相同的分页参数。使用 `offset` 与 `limit`（或 `page` 与 `hitsPerPage`）进行平滑翻页：

<CodeGroup>

```bash
curl \
  -X POST 'MEILISEARCH_URL/indexes/movies/search' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer MEILISEARCH_KEY' \
  --data-binary '{
    "q": "",
    "limit": 20,
    "offset": 40
  }'
```

</CodeGroup>
