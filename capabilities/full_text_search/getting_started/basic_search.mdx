全文检索是 Meilisearch 最核心的灵魂特性。一旦索引中写入了文档，你只需发送一个简单的查询语句，就能在数毫秒内获得高度相关的结果。

如果你还没有添加任何文档，请先参阅[数据索引入门指南](/capabilities/indexing/getting_started)。

## 发起搜索请求

通过向索引的 `/search` 端点发送带 `q`（Query）参数的请求：

<CodeGroup>

```bash
curl -X POST 'MEILISEARCH_URL/indexes/movies/search' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer MEILISEARCH_KEY' \
  --data-binary '{
    "q": "galaxy"
  }'
```

</CodeGroup>

Meilisearch 会返回包含匹配文档的 JSON 响应：

<CodeGroup>

```json
{
  "hits": [
    {
      "id": 24,
      "title": "Guardians of the Galaxy",
      "overview": "A group of intergalactic criminals are forced to work together...",
      "genres": ["Action", "Science Fiction"]
    },
    {
      "id": 25,
      "title": "The Hitchhiker's Guide to the Galaxy",
      "overview": "Mere seconds before the Earth is to be demolished...",
      "genres": ["Adventure", "Comedy", "Science Fiction"]
    }
  ],
  "query": "galaxy",
  "processingTimeMs": 1,
  "limit": 20,
  "offset": 0,
  "estimatedTotalHits": 2
}
```

</CodeGroup>

## 响应字段详解

| 响应字段 | 字段说明 |
| :--- | :--- |
| `hits` | 匹配到的文档数组，已默认按相关度从高到低排序 |
| `query` | 实际接收并执行的搜索词 |
| `processingTimeMs` | 搜索引擎底层完成检索所消耗的时间（毫秒数） |
| `limit` | 本次请求返回的最大文档数（默认：20） |
| `offset` | 翻页跳过的文档数量（用于分页定位） |
| `estimatedTotalHits` | 预估符合查询条件的命中总条数 |

## 错别字容错体验

Meilisearch 全自动处理打字错误。即使用户搜 "galxy" 或 "galaxi"，依然能够精准命中 "galaxy"：

<CodeGroup>

```bash
curl -X POST 'MEILISEARCH_URL/indexes/movies/search' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer MEILISEARCH_KEY' \
  --data-binary '{
    "q": "galxy"
  }'
```

</CodeGroup>

这归功于 Meilisearch 内置的[错别字容错算法](/capabilities/full_text_search/relevancy/typo_tolerance_settings)，它可以在极小的时间损耗下计算编辑距离，完成近似词召回。

## 多词组合搜索

当搜索词包含多个单词时，Meilisearch 会检索包含其中任一词汇的文档，并根据“命中的词汇数量多少”自动加权排序：

<CodeGroup>

```bash
curl -X POST 'MEILISEARCH_URL/indexes/movies/search' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer MEILISEARCH_KEY' \
  --data-binary '{
    "q": "dark knight"
  }'
```

</CodeGroup>

同时包含 "dark" 和 "knight" 两个词的文档，排序权重会显著高于仅包含其中一个词的文档。你可以通过[匹配策略 (Matching Strategy)](/capabilities/full_text_search/how_to/use_matching_strategy)对这一行为进行精细控制。

## 数量限制与分页控制

通过 `limit` 和 `offset` 精确控制返回数量和分页位置：

<CodeGroup>

```bash
curl -X POST 'MEILISEARCH_URL/indexes/movies/search' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer MEILISEARCH_KEY' \
  --data-binary '{
    "q": "action",
    "limit": 5,
    "offset": 10
  }'
```

</CodeGroup>

以上请求将跳过前 10 条结果，从第 11 条开始提取 5 条文档返回。
