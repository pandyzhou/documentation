搜索片段（Search snippets）允许你提取并展示文档中与用户查询词最契合的局部文本，并对命中的词汇进行视觉高亮。这能帮助用户无需通读几千字的完整文档，即可在瞬间判定该条结果是否正是自己所需的。

Meilisearch 为此提供了两项相辅相成的原生能力：
- **关键词高亮 (Highlighting)**：用指定标签包裹命中词（默认 `<em>`）；
- **上下文裁剪 (Cropping)**：截断冗长的大段文本，仅保留命中词前后最相关的上下文窗口。

## 关键词高亮 (Highlighting)

使用 `attributesToHighlight` 参数声明哪些字段中的命中词需要被高亮标签包裹。传入 `["*"]` 可对所有[展示字段](/capabilities/full_text_search/how_to/configure_displayed_attributes)启用高亮。

<CodeGroup>

```bash
curl \
  -X POST 'MEILISEARCH_URL/indexes/movies/search' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer MEILISEARCH_KEY' \
  --data-binary '{
    "q": "american hero",
    "attributesToHighlight": ["title", "overview"]
  }'
```

</CodeGroup>

响应中的每篇命中结果都会额外附带一个 `_formatted` 对象。在该对象内部，匹配到的关键词默认被 `<em>` 标签包裹：

<CodeGroup>

```json
{
  "hits": [
    {
      "title": "Captain America: The First Avenger",
      "overview": "An American hero rises during World War II...",
      "_formatted": {
        "title": "Captain <em>America</em>: The First Avenger",
        "overview": "An <em>American</em> <em>hero</em> rises during World War II..."
      }
    }
  ]
}
```

</CodeGroup>

### 自定义高亮标签

使用 `highlightPreTag` 与 `highlightPostTag` 参数替换默认的 `<em>` 标签，以便与你的前端 CSS 样式类对接：

<CodeGroup>

```bash
curl \
  -X POST 'MEILISEARCH_URL/indexes/movies/search' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer MEILISEARCH_KEY' \
  --data-binary '{
    "q": "american hero",
    "attributesToHighlight": ["title", "overview"],
    "highlightPreTag": "<mark>",
    "highlightPostTag": "</mark>"
  }'
```

</CodeGroup>

## 裁剪超长文本字段 (Cropping)

使用 `attributesToCrop` 裁剪长文本字段，使得结果中仅返回命中词周边的紧凑文字窗口。这在文章详情、正文描述或日志字段中极其有用。

<CodeGroup>

```bash
curl \
  -X POST 'MEILISEARCH_URL/indexes/movies/search' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer MEILISEARCH_KEY' \
  --data-binary '{
    "q": "romance",
    "attributesToCrop": ["overview"],
    "cropLength": 20
  }'
```

</CodeGroup>

返回的 `_formatted` 对象将呈现被精炼裁剪后的文本：

<CodeGroup>

```json
{
  "_formatted": {
    "overview": "...a sweeping romance set in the heart of..."
  }
}
```

</CodeGroup>

### 裁剪参数说明

| 参数名称 | 默认值 | 参数功能说明 |
| :--- | :--- | :--- |
| `attributesToCrop` | `null` | 需要进行裁剪的字段列表。传入 `["*"]` 代表裁剪所有展示字段。 |
| `cropLength` | `10` | 裁剪后的最大词数窗口（Window length）。 |
| `cropMarker` | `"..."` | 在裁剪文本的前后用于指示文本被截断的省略标记字符串。 |

### 为不同字段单独定制裁剪长度

你可以通过在字段名后追加 `:length`，针对不同的字段指定不同的裁剪长度：

<CodeGroup>

```bash
curl \
  -X POST 'MEILISEARCH_URL/indexes/movies/search' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer MEILISEARCH_KEY' \
  --data-binary '{
    "q": "adventure",
    "attributesToCrop": ["overview:30", "tagline:10"]
  }'
```

</CodeGroup>

## 黄金组合：同时启用高亮与裁剪

为了给用户提供最佳的搜索体验，**强烈建议同时结合使用高亮与裁剪**。这样能够呈现出兼顾“短小精炼”与“命中词视觉聚焦”的专业结果摘要：

<CodeGroup>

```bash
curl \
  -X POST 'MEILISEARCH_URL/indexes/movies/search' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer MEILISEARCH_KEY' \
  --data-binary '{
    "q": "space adventure",
    "attributesToHighlight": ["title", "overview"],
    "attributesToCrop": ["overview"],
    "cropLength": 30,
    "highlightPreTag": "<mark>",
    "highlightPostTag": "</mark>"
  }'
```

</CodeGroup>

最终由 `_formatted` 提供的渲染效果：

<CodeGroup>

```json
{
  "_formatted": {
    "title": "<mark>Space</mark> Odyssey",
    "overview": "...embark on a daring <mark>space</mark> <mark>adventure</mark> to save humanity from..."
  }
}
```

</CodeGroup>

<Tip>
若某个字段同时被列入 `attributesToCrop` 和 `attributesToHighlight`（或 `attributesToHighlight` 设为了 `["*"]`），裁剪后的文本片段内部会自动包含高亮标记。
</Tip>

<Info>
如需查阅全部搜索参数与高级选项，请参考[搜索 API 参考手册](/reference/api/search/search-with-post)。
</Info>
