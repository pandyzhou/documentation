精确短语搜索允许用户通过将查询词用双引号（`""`）包裹，来检索包含**严格连续特定词序**的文档。当词语的顺序和相邻关系至关重要时（例如查找特定电影片名、固定成语熟语或专业技术术语），短语搜索极其有效。

## 工作原理

当你把搜索语句的部分或全部用双引号括起来时，Meilisearch 会将引号内的内容作为一个不可分割的短语对待。引擎不会单独分散匹配各个单词，而是要求这些词汇必须以指定的顺序、彼此紧挨着连续出现。

例如查询 `"african american" horror` 包含一个精确短语（`african american`）和一个普通词汇（`horror`）。Meilisearch 会检索所有同时满足以下条件的文档：一方面 "african" 与 "american" 必须相邻连续出现，另一方面文档中还要包含 "horror"。

## 响应示例

在 `movies` 电影索引中，搜索 `"african american" horror` 将返回：

<CodeGroup>

```json
{
  "hits": [
    {
      "id": 3021,
      "title": "Tales from the Hood",
      "overview": "A funeral director tells four African American horror stories..."
    }
  ],
  "query": "\"african american\" horror"
}
```

</CodeGroup>

如果某篇文档中分别零散出现了 "african" 和 "american" 但它们并不相邻，则**无法**匹配该短语部分。

## 短语搜索与匹配策略的关系

短语搜索会与[匹配策略 (Matching Strategy)](/capabilities/full_text_search/how_to/use_matching_strategy)参数相互作用。引号内的短语始终被视作一个**必须满足的核心条件**。当短语与普通词汇混用时，匹配策略将作用于那些额外的普通词汇。

例如，对于查询语句 `"science fiction" adventure comedy`：

- **`last` 策略**（默认）：文档必须包含短语 "science fiction"；而普通词 "adventure" 和 "comedy" 遵循常规策略，在结果不足时次要词汇允许被自动忽略。
- **`all` 策略**：文档必须同时包含短语 "science fiction" 以及两个普通词 "adventure" 和 "comedy"。

## 单次查询中包含多个短语

你可以在单个搜索请求中包含多个被引号包裹的独立短语：

<CodeGroup>

```bash
curl \
  -X POST 'MEILISEARCH_URL/indexes/movies/search' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer MEILISEARCH_KEY' \
  --data-binary '{
    "q": "\"star wars\" \"empire strikes\""
  }'
```

</CodeGroup>

文档必须分别按顺序包含每个被引用的完整短语才能命中。

## 适用场景

- **专有名词或特定书影音标题**：搜 `"指环王"` 或 `"The Lord of the Rings"`，避免零散匹配分散出现的词汇
- **专业技术术语**：搜 `"machine learning"`（机器学习）定位专业概念，而不是分别寻找孤立出现的 "machine" 和 "learning"
- **特定引言或固定搭配**：搜 `"生存还是毁灭"` 或 `"to be or not to be"`
