Meilisearch 允许通过 `/multi-search` 端点同时发起多组检索操作。**联合搜索（Federated search）**是一种特殊形态的多索引搜索，它将跨多个不同索引检索到的结果聚合打分，最终作为一个统一的大列表返回。

本教程以 CRM 客户关系管理系统为例，演示如何为不同类型的数据建立独立索引，并通过单次联合搜索一键搞定全库检索。

## 场景准备：创建三个独立索引

下载以下三个模拟 CRM 业务数据集：<a href="https://www.meilisearch.com/docs/assets/datasets/crm-chats.json" download="crm-chats.json">`crm-chats.json`（沟通聊天记录）</a>、<a href="https://www.meilisearch.com/docs/assets/datasets/crm-profiles.json" download="crm-profiles.json">`crm-profiles.json`（客户档案）</a> 以及 <a href="https://www.meilisearch.com/docs/assets/datasets/crm-tickets.json" download="crm-tickets.json">`crm-tickets.json`（售后工单）</a>。

分别创建 `profiles`、`chats` 和 `tickets` 三个独立的索引并导入数据：

<CodeGroup>

```sh
curl -X POST 'MEILISEARCH_URL/indexes/profiles' -H 'Content-Type: application/json' -H 'Authorization: Bearer MEILISEARCH_KEY' --data-binary @crm-profiles.json &&
curl -X POST 'MEILISEARCH_URL/indexes/chats' -H 'Content-Type: application/json' -H 'Authorization: Bearer MEILISEARCH_KEY' --data-binary @crm-chats.json &&
curl -X POST 'MEILISEARCH_URL/indexes/tickets' -H 'Content-Type: application/json' -H 'Authorization: Bearer MEILISEARCH_KEY' --data-binary @crm-tickets.json
```

</CodeGroup>

通过任务接口确认所有数据集建索就绪后，即可开启联合搜索。

## 联合搜索分页支持

在 `federation` 对象中传入 `page` 与 `hitsPerPage`，即可跨多个索引进行经典的精准按页翻页：

<CodeGroup>

```bash
curl \
  -X POST 'MEILISEARCH_URL/multi-search' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer MEILISEARCH_KEY' \
  --data-binary '{
    "federation": {
      "page": 2,
      "hitsPerPage": 10
    },
    "queries": [
      { "indexUid": "profiles", "q": "Nguyen" },
      { "indexUid": "chats", "q": "Nguyen" },
      { "indexUid": "tickets", "q": "Nguyen" }
    ]
  }'
```

</CodeGroup>

响应中将包含针对全局合并后数据的 `page`、`hitsPerPage`、`totalHits` 与 `totalPages`，极其便于直接驱动前端分页组件。

## 跨索引自动去重 (`federation.distinct`)

如果同一个客户既有档案又有聊天记录，你不希望她在合并列表里被多条重复刷屏。可以在 `federation` 级别配置 `distinct` 参数：

首先确保三个索引中都把去重字段（如 `client_name`）声明为 `filterableAttributes`，然后在请求中加上：

<CodeGroup>

```bash
curl \
  -X POST 'MEILISEARCH_URL/multi-search' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer MEILISEARCH_KEY' \
  --data-binary '{
    "federation": {
      "distinct": "client_name"
    },
    "queries": [
      { "indexUid": "profiles", "q": "Nguyen" },
      { "indexUid": "chats", "q": "Nguyen" },
      { "indexUid": "tickets", "q": "Nguyen" }
    ]
  }'
```

</CodeGroup>

每个客户在合并后的结果集中仅会保留最相关的一篇代表文档。
