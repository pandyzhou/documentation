Meilisearch 是一个不依赖任何外部组件的单一独立二进制程序。你可以在任何 Linux、macOS 或 Windows 机器上运行它，支持物理裸机运行或容器化部署。

<Tip>
[Meilisearch Cloud](https://www.meilisearch.com/cloud?utm_campaign=oss&utm_source=docs&utm_medium=self-hosting-overview) 是官方推荐的全托管运行方案。它会自动为你处理硬件资源配置、弹性扩缩容、安全合规与版本升级。自托管则赋予你对自己底层基础设施的 100% 绝对控制权。
</Tip>

## 为什么选择自托管？

自托管部署在以下业务场景中尤为契合：

- **完全掌控基础设施**：自由选择服务器提供商、内网拓扑结构与存储硬件配置
- **严格的数据合规与隐私常驻**：将敏感数据保存在特定地理管辖区域的机房或企业本地物理内网
- **无缝融合现有发布流水线**：将 Meilisearch 作为标准服务纳入现有的 Kubernetes、Docker Compose 或 CI/CD 编排体系
- **离线与断网运行环境（Air-gapped）**：在完全断开外网连接的保密内网环境中平稳运行

## 硬件与环境准备

- 一台运行着[受支持操作系统](/resources/self_hosting/getting_started/install_locally#supported-operating-systems)的服务器
- 至少 256 MB 内存（大规模数据集请参考[性能与内存指南](/resources/self_hosting/performance/ram_multithreading)）
- Meilisearch 官方二进制，支持通过 [直接下载、Docker 容器、Homebrew 或 APT 软件包](/resources/self_hosting/getting_started/install_locally) 获取

在生产环境正式上线时，你通常还需要配置：

- 反向代理服务（如 Nginx、Caddy 或 Traefik）用于处理 HTTPS 证书终止
- 守护进程管理（如 systemd 或 Docker restart 策略）保障崩溃自动拉起
- 配置强密码 [主密钥 (Master key)](/resources/self_hosting/security/overview) 保障 API 鉴权安全
