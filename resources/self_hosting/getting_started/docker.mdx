在本指南中，你将学习如何通过 Docker 拉取并运行 Meilisearch、传入参数配置引擎，以及如何安全地持久化管理你的索引数据。

Docker 容器能够确保应用程序在不同开发机器与服务器环境之间保持完全一致的行为。本地开发建议参考 [Docker Desktop 官方安装指引](https://docs.docker.com/get-docker/)。

## 下载 Meilisearch Docker 镜像

通过 `docker pull` 命令下载官方镜像：

```sh
docker pull getmeili/meilisearch:latest
```

Meilisearch 每次发布新版本时都会同步推送新的 Docker 镜像。每个镜像都打上了对应的版本 Tag。你可以在 Docker Hub 上查看 [所有受支持的 Meilisearch 镜像版本列表](https://hub.docker.com/r/getmeili/meilisearch/tags#!)。

<Warning>
`latest` 标签始终会拉取最新的版本。在生产环境中，**强烈建议锁定具体版本号（例如 `v1.11` 或 `v1.12`）**，避免不同服务器因拉取镜像时间不同而导致运行了不一致的版本。
</Warning>

## 启动 Meilisearch 容器

拉取完成后，使用 `docker run` 命令启动容器：

```sh
docker run -it --rm \
  -p 7700:7700 \
  -v $(pwd)/meili_data:/meili_data \
  getmeili/meilisearch:latest
```

### 配置启动参数

Meilisearch 在启动时支持丰富的配置项，你可以通过两种方式传入：环境变量（Environment Variables）或命令行参数（CLI Flags）。[查阅完整配置参考手册了解详情](/resources/self_hosting/configuration/overview)。

#### 方式一：通过环境变量配置（最推荐）

向 `docker run` 附加 `-e` 参数。以下示例配置了主密钥（Master Key）：

```sh
docker run -it --rm \
  -p 7700:7700 \
  -e MEILI_MASTER_KEY='YOUR_STRONG_MASTER_KEY' \
  -v $(pwd)/meili_data:/meili_data \
  getmeili/meilisearch:latest
```

#### 方式二：通过命令行参数配置

如果你需要直接传递 CLI 参数，在 `docker run` 末尾显式调用 `meilisearch` 启动命令：

```sh
docker run -it --rm \
  -p 7700:7700 \
  -v $(pwd)/meili_data:/meili_data \
  getmeili/meilisearch:latest \
  meilisearch --master-key="YOUR_STRONG_MASTER_KEY"
```

## 数据管理与持久化

在 Docker 容器内部，默认的工作目录为 `/meili_data`。这意味着数据库的核心文件存储在容器内的 `/meili_data/data.ms` 路径下。

### 数据卷持久化挂载 (-v)

默认情况下，写入 Docker 容器可写层的数据会在容器停止或删除时彻底丢失（包括你的全部索引和文档）。

**为了在容器重启后数据依然完好无损，必须使用 `-v` 参数挂载宿主机目录或 Docker 数据卷**：

```sh
docker run -it --rm \
  -p 7700:7700 \
  -v $(pwd)/meili_data:/meili_data \
  getmeili/meilisearch:latest 
```

上述命令将当前目录下的 `meili_data` 映射到容器内的 `/meili_data`。

### 导出与导入转储包 (Dumps) 实现跨版本升级

当需要进行 Meilisearch 跨大版本升级时，必须使用 Dump：

1. **导出 Dump**：调用创建转储接口，生成的文件将保存在挂载目录的 `/meili_data/dumps` 下。
2. **导入 Dump**：在启动新版本容器时，传入 `--import-dump` 参数：

```sh
docker run -it --rm \
  -p 7700:7700 \
  -v $(pwd)/meili_data:/meili_data \
  getmeili/meilisearch:latest \
  meilisearch --import-dump /meili_data/dumps/20261108-042312213.dump
```

<Warning>
如果挂载的数据卷中已经存在旧版的 `data.ms`，在导入新 Dump 之前**必须先删除或重命名旧的 `/meili_data/data.ms` 目录**。
</Warning>

### 快照备份 (Snapshots)

定时快照用于单节点快速容灾备份：

```sh
docker run -it --rm \
  -p 7700:7700 \
  -v $(pwd)/meili_data:/meili_data \
  getmeili/meilisearch:latest \
  meilisearch --schedule-snapshot --snapshot-dir /meili_data/snapshots
```

如需从快照镜像还原启动：

```sh
docker run -it --rm \
  -p 7700:7700 \
  -v $(pwd)/meili_data:/meili_data \
  getmeili/meilisearch:latest \
  meilisearch --import-snapshot /meili_data/snapshots/data.ms.snapshot
```
