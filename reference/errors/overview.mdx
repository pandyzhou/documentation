Meilisearch 在请求成功或失败时遵循标准 HTTP 状态码规范：

| HTTP 状态码 | 英文标识 | 含义说明 |
| :--- | :--- | :--- |
| **200** | ✅ **OK** | 请求成功执行并返回预期数据 |
| **201** | ✅ **Created** | 同步资源已成功创建 |
| **202** | ✅ **Accepted** | 异步任务已成功进入队列排队（写操作常见返回） |
| **204** | ✅ **No Content** | 资源已被删除，或无需返回内容 |
| **205** | ✅ **Reset Content** | 资源已被清空重置 |
| **400** | ❌ **Bad Request** | 客户端请求参数不合法（如缺少必填字段或格式错误） |
| **401** | ❌ **Unauthorized** | 未提供有效的 API Key 鉴权凭据 |
| **403** | ❌ **Forbidden** | 当前 API Key 权限不足，无法执行该敏感操作 |
| **404** | ❌ **Not Found** | 请求的目标资源（如指定的 index 索引）不存在 |

## 错误类型 (Error Types)

所有失败的异步任务详情与同步报错请求，均会附带标准 JSON 格式的错误对象。错误主要归为以下四类：

| 错误分类 (Type) | 核心特征说明 | 对应状态码 |
| :--- | :--- | :--- |
| **`invalid_request`** | 客户端输入参数错误、格式不合规或请求体损坏 | `4xx` |
| **`auth`** | 鉴权失败、API Key 缺失、过期或越权操作 | `4xx` |
| **`system`** | 底层系统资源耗尽：磁盘空间满、达到最大打开文件句柄上限或无读写权限 | `5xx` |
| **`internal`** | 引擎内部未捕获的严重故障或配置环境冲突 | `5xx` |

### 错误响应格式

```json
{
  "message": "Index `movies` not found.",
  "code": "index_not_found",
  "type": "invalid_request",
  "link": "https://docs.meilisearch.com/errors#index_not_found"
}
```

| 返回字段 | 数据类型 | 字段说明 |
| :--- | :--- | :--- |
| **`message`** | String | 适合人类可读的具体错误原因描述 |
| **`code`** | String | 固定的机器友好型[标准错误代码](/reference/errors/error_codes) |
| **`type`** | String | 错误所属的大分类（`invalid_request`、`auth`、`system`、`internal`） |
| **`link`** | String | 指向官方文档中该错误专项排查指南的快捷跳转链接 |

如果你需要查询具体的错误代码释义，请翻阅[完整错误码速查表](/reference/errors/error_codes)。
