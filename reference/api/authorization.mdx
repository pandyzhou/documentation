<Tip>
如果你刚刚接触 Meilisearch，请先参阅[自托管快速上手指南](/resources/self_hosting/getting_started/quick_start)。
</Tip>

通过在[启动时配置 Master Key 主密钥](/resources/self_hosting/security/basic_security)，你可以彻底保护 Meilisearch 实例免受未授权访问。主密钥长度必须**至少为 16 字节**。从设置密钥起，除健康检查路由（[`/health`](/reference/api/health)）外，访问所有受保护的 API 端点都必须在 HTTP 请求头中附带 `Authorization: Bearer <API_KEY>`。

<CodeSamplesAuthorizationHeader1 />

[`/keys`](/reference/api/keys) 密钥管理路由**只能使用 Master Key 进行访问**。出于安全最佳实践，对于其他业务路由，强烈建议使用派生出的普通 API 密钥（如专用搜索 Key）。

[深入了解密钥分级与安全配置，请参阅安全指南 →](/resources/self_hosting/security/basic_security)
