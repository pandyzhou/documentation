## 参数分类 (Parameters)

参数用于向端点传递控制指令，调整接口行为与响应。Meilisearch REST API 中主要包含三大类参数：

### 1. 请求体参数 (Request body parameters)
通过 POST、PUT 和 PATCH 请求的 Body 数据中发送。根据具体修改的资源类型，支持对象、数组、字符串或布尔值等丰富的 JSON 结构。

### 2. 路径参数 (Path parameters)
嵌入在 URL 路径本身之中的参数，用于唯一定位某个具体的资源。例如在 `/indexes/{index_uid}/documents/{document_id}` 中，`index_uid` 和 `document_id` 就是路径参数。

### 3. 查询字符串参数 (Query parameters)
出现在 URL 问号（`?`）之后的键值对，多个参数之间用 `&` 连接，常见于 GET 检索和列表接口（如 `?limit=10&offset=20`）。参数的排列先后顺序不影响解析。

## 请求体格式 (Request Body)

客户端向服务端提交的请求体数据必须为标准合法的 JSON 格式（批量导入文档时可额外支持 NDJSON 和 CSV）。

## 异步响应机制 (Asynchronous Response)

Meilisearch 的写操作（写文档、删数据、改配置、建索引等）采用**完全异步化设计**。这意味着在发送写请求后，服务端不会阻塞等待建索完毕，而是立即返回一个轻量级的 `task` 任务对象，代表该操作已经进入底层任务队列排队：

```json
{
    "taskUid": 1,
    "indexUid": "movies",
    "status": "enqueued",
    "type": "indexUpdate",
    "enqueuedAt": "2026-11-08T09:25:53.000000Z"
}
```

客户端拿到 `taskUid` 后，可以调用[任务详情接口](/reference/api/tasks/get-task)轮询其实际执行进度。
