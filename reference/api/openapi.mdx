title: OpenAPI 接口定义规范
sidebarTitle: OpenAPI 规范
description: 下载与查阅 Meilisearch 官方发布的 OpenAPI (Swagger) 规范文件。
---

你可以直接下载最新版 Meilisearch 的 <a href="https://www.meilisearch.com/docs/assets/release-assets/meilisearch-openapi.json" download="meilisearch-openapi.json">OpenAPI 规范 JSON 文件</a>，并将其导入到 Postman、Apifox 或 Swagger Editor 等可视化工具中进行交互式调试。

如需下载特定历史版本的接口规范，请前往 [GitHub Releases 发布页面](https://github.com/meilisearch/meilisearch/releases)。官方发布的每个版本附件（Assets）中均打包了对应的 `meilisearch-openapi.json`。
